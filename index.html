Or run any agent in a sandbox

Pick Nemesis8 Sandbox as the agent for any tab and it runs inside an isolated Nemesis8 Docker container instead of directly on your machine, so its blast radius stays off your host. Add a gateway under Preferences → Nemesis8 Sandboxes. One click sets one up locally, or point it at a remote one. Add more than one and each shows up in the agent picker as Nemesis8: <name>, so a sandboxed Claude and a sandboxed Codex can run side by side.

And they share what they find

Agents in a session leave each other notes. When one moves a port, changes a schema, or hits something the next one would trip over, it writes that down. The notes are shared by every repo in the session and live outside your repository, so nothing lands in a commit and a teammate on another branch never sees them. Whichever agent picks the work up next gets handed the recent ones as current.

Below: a session started on Antigravity, which writes a note about the colour change it is planning. Claude Opus and Codex open as new tabs in the same session and both read it.

Full Dev Loop · “Rest of the Owl”

Hand it a ticket. Come back to a green PR.

  2. 02Implementation

  9. 09Notify when Green
  10. —Merge stays yours

FAQ

Does my code get sent to third parties?

When you use an agent, your prompts and repo context go to whichever provider you picked, through the CLI you already trust. GitHub, GitLab, and Bitbucket operations go through your local CLIs (gh, glab) and direct forge authentication. Inline autocomplete runs on your machine via Ollama and qwen2.5-coder:1.5b, so nothing per-keystroke leaves it. We don't run a server of our own.

Do I need a subscription, and does Klaussy mark up AI usage?

You need whatever plan each agent CLI is set up with, on your own accounts. Klaussy never sits between you and your provider, so there's nothing to resell, mark up, or meter. Or run free and local models through Ollama and pay for nothing at all.

What is klaussy-agents?

klaussy-agents is the engine underneath the desktop app: the conventions, custom skills, and git-level guardrails that keep agents aligned with your codebase. The desktop is the face, the engine is the spine. It's open source under the MIT license.

Which platforms are supported?

macOS 12+ (Apple Silicon and Intel), Windows 10/11, and Ubuntu 22.04+ (other modern Linux distros generally work). All builds are signed where the platform supports it.

Why the 2 GB download prompt for inline autocomplete?

~500 MB is Ollama's runtime, ~1 GB is the qwen2.5-coder:1.5b model weights. You only see the prompt if you opt in. Otherwise a free word-based completer handles Tab.

What happens to my data if I uninstall?

On macOS, remove ~/Library/Application Support/Klaussy and ~/Library/Logs/Klaussy. On Windows, remove %APPDATA%\Klaussy. On Linux, remove ~/.config/Klaussy and ~/.local/share/Klaussy. Ollama and its models stick around on their own, so uninstall it through your package manager and remove ~/.ollama.

Is this open source, and what is SUL 1.0?

Klaussy Desktop is source-available under the Sustainable Use License. You can inspect, modify, run, and self-host it for personal use, development, and internal business use. Commercial production use needs a separate agreement, and you can't use it to host a competing service, so get in touch if you want to partner. The engine underneath, klaussy-agents, is fully open source under MIT. Bundled components are listed in About → Licenses.
